# Как пользоваться админ-панелью

Адрес: **адрес-вашего-сайта/admin/**, например https://ivan.artwillkrd.ru/admin/.
Вход по паролю, который вам выдали при создании сайта. Всё, что вы сохраняете, сразу появляется на сайте.

**Первым делом:** «Настройки» → смените пароль, впишите название сайта и куда присылать заявки (почта и/или MAX).

## Разделы

| Раздел | Что в нём |
|---|---|
| **Страницы** | Все страницы сайта. Нажмите на страницу — откроется редактор. Здесь же: создать страницу, скопировать, удалить, поменять заголовок, описание и адрес (шестерёнка) |
| **Общие блоки** | То, что повторяется на многих страницах: шапка с меню, подвал, форма заявки. Меняете один раз — обновляется везде |
| **Шаблоны блоков** | Заготовки для вставки на страницы: секции, карточки, формы, кнопки. Можно менять и добавлять свои |
| **Изображения** | Все фото сайта. Загруженные фото сайт сам уменьшает до нужных размеров |
| **Оформление** | Цвета и шрифты всего сайта, скругление углов, размер текста. Можно загрузить свой шрифт |
| **Заявки** | Все заявки с форм сайта. Можно скачать таблицей |
| **Настройки** | Название сайта, куда присылать заявки (почта, MAX), смена пароля |

## Редактор страницы

- **Текст** — нажмите на него и печатайте. Enter — новая строка, Esc — закончить.
  Выделите часть текста, чтобы сделать её жирной, акцентной, ссылкой или другого цвета (панель справа, «Выделенный текст»).
- **Картинка** — нажмите на неё → «Заменить изображение». Можно выбрать из загруженных или загрузить новую.
- **Кнопка или ссылка** — нажмите → справа поле «Адрес».
- **Шрифт, размер, цвет, выравнивание, фон, рамка, отступы, ширина** — справа, для любого выбранного элемента.
- **Чёрная панелька над элементом**: выбрать внешний блок, выше / ниже, дублировать, добавить блок рядом, удалить.
- **Строка «Секция › Блок › Заголовок»** вверху правой панели — переход к внешним блокам; «Внутри:» — к вложенным.
- **Кнопка «Блок»** — вставить готовый шаблон: секцию, карточки, форму заявки, кнопку, картинку.
- **Формы**: нажмите на поле формы → справа «Форма заявки»: название заявки и «Добавить поле».
  Подписи полей меняются прямо на странице. Заявки с любых форм попадают в раздел «Заявки», а также на почту и в MAX, если они указаны в «Настройках».
- **Сверху**: вид на компьютере / планшете / телефоне, отмена и возврат (Ctrl+Z), «глаз» — показать скрытое
  (мобильное меню, окно «Быстрый вопрос»), код страницы, история изменений, настройки страницы, «Сохранить» (Ctrl+S).
- Оранжевая рамка — это общий блок (шапка, подвал, общая форма). Нажмите → «Изменить общий блок».

## Если что-то пошло не так

- **Отмена** (Ctrl+Z) — пока страница не закрыта.
- **История изменений** (значок часов в редакторе) — вернуть любую из последних 40 сохранённых версий страницы.
- Удалённая страница тоже остаётся в истории на сервере — её может восстановить администратор сервера.
- Забыли пароль — попросите администратора сервера выдать новый (`sitectl password`).

## Советы

- Новую страницу проще всего сделать копией похожей: «Страницы» → значок копии → заменить тексты и фото.
- Заголовок для поисковиков — до 60 знаков, описание — до 160 (счётчики есть в настройках страницы).
- После создания страницы добавьте ссылку на неё в меню: «Общие блоки» → «Шапка сайта и меню».
- Свои работы: «Страницы» → «Мои работы» → нажмите на фото → «Заменить изображение». Лишние фото удаляются кнопкой корзины, новые — кнопкой дублирования.
- Нужна ещё одна страница (например, «Обо мне»)? «Страницы» → «Новая страница», затем добавьте её в меню.
